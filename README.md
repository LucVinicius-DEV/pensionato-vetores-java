# 🏨 Pensionato

Programa desenvolvido em Java que simula o aluguel de quartos em um pensionato, com base em dados inseridos via terminal.

## ✨ Funcionalidades

- Definição da quantidade de quartos disponíveis.
- Leitura de dados do estudante (nome, e-mail e número do quarto).
- Verificação de ocupação dos quartos.
- Exibição dos quartos ocupados com os dados dos respectivos estudantes.

## ▶️ Como executar

1. Compile o arquivo `Main.java` utilizando uma IDE ou o terminal.
2. Execute o programa.
3. Insira os dados conforme solicitado pelo terminal.
